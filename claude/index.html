概念入門

Chat / Cowork / Code 到底差在哪?

同樣是 Claude,三條產品線分別服務不同情境。Cowork 是「能動手做事的 Claude」,而不是「會回答問題的 Claude」。

Chat · 對話

給建議的 Claude

瀏覽器或手機 App,一問一答的聊天介面。

  • 需要手動上傳、下載檔案
  • 一問一答,單一步驟為主
  • 輸出純文字或可下載檔
Cowork · 同事

能動手做事的 Claude

桌面 App,委派任務,看著它跑、或下班再回來看成果。

  • 直接讀寫本地授權資料夾
  • 自主規劃、持續推進多步驟
  • 真實可用的 .xlsx、.docx、.pptx
Code · 開發者

給工程師的 Claude

CLI 終端機介面,操控整個專案 codebase。

  • 整個 repo 的檔案系統存取
  • 多代理協作、執行指令
  • commits、PR、跑測試

記住口訣:Chat 優先;有開發需求用 Code;需操作本機檔案用 Cowork。

核心心智模型

Cowork 強大背後的四大基礎建設

Cowork 不是單一功能,而是四個元件組成的工作系統。理解這四件事,所有進階操作都會變直覺。

01
📂

指定資料夾

安全邊界 + 工作區

Claude 只能在這個資料夾內讀寫。Allow 是單次授權、Always Allow 是永久。所有檔案、輸出、記憶都集中在這裡。

→ 看文件生成怎麼用
02
🧠

CLAUDE.md

專案記憶與行為準則

Cowork 自動生成的記憶文件。每次進入專案,Claude 會先讀它,當作工作準則。把用字、規範、敏感資料處理寫進去一次,長期受用。

→ 看 CLAUDE.md 細節
03
📚

Skill

可重用的 SOP 說明書

把常用工作流封裝成「斜線指令」。Claude 平時不載入,需要才翻閱。比寫進 CLAUDE.md 更省 context。可瀏覽範本、Skill Creator 互動建立、或手動填寫。

→ 看 Skill 完整玩法
04
🔌

Connector

外部工具串接

讓 Cowork 操作 Canva、Google 日曆、Gmail、Slack、Notion 等服務。授權一次,以後 Claude 能跨平台讀寫、自動化重複任務。

→ 看 Connectors 範例
🎯
一句話總結:Cowork 把 Claude 從「被動聊天工具」升級成「會主動值勤、能跨工具實際完成工作的數位助理」。這四個基礎建設就是讓它能值勤的水電瓦斯。

    執行計畫

    💡
    觀察重點:Cowork 不是直接執行,而是先「展示計畫 → 等你核准 → 邊做邊回報」。任何時候你都可以喊停、補充、修正,這是它跟自動腳本最大的差別。
    真實場景

    六大真實應用情境,從指令到產出

    根據官方文件整理,涵蓋不同工作類型。每個情境拆解:Claude 具體會怎麼做、指令怎麼下、適合誰用、可以怎麼搭配其他功能。

    01
    📂

    資料夾自動整理

    雜亂的 Downloads 資料夾是許多人的痛點。只要對 Cowork 說一句話,它就能在幾分鐘內處理完幾百個檔案,並告訴你它動了哪些東西。面對上百個雜亂檔名,它會先用樣本分析命名規則,提出分類方案讓你核准,批次處理時保留原始檔備份。

    整理 Downloads 資料夾,依照檔案類型分類,重新命名為 YYYY-MM-DD 格式,輸出一份整理清單
    適合誰:有大量截圖、PDF 收據、散落文件,或需要定期整理的使用者
    💡
    這類定期整理工作可搭配排程功能,每週自動執行一次,不用再手動觸發。
    02
    🔬

    研究報告自動生成

    想了解某個主題,傳統做法是自己搜尋、讀文章、整理重點、撰寫摘要。Cowork 可以幫你一次完成整條流程:

    聯網搜尋最新資訊→彙整多個來源→依指定架構輸出 Word 報告→附上下一步行動建議
    適合誰:需要定期追蹤產業動態的行銷人員、研究人員,或需要快速了解新領域的決策者
    03
    📊

    Excel 資料分析與視覺化

    把原始數據(CSV、截圖、PDF 表格)丟進 Inbox 資料夾,告訴 Claude 你想分析什麼,它能輸出含公式、條件式格式、圖表的完整 Excel 檔案。不同於一般 AI 只輸出純文字建議,Cowork 產出的是可以直接編輯、繼續使用的真實檔案。票據報帳就是典型例子:它會用 OCR 辨識收據截圖的店家、金額、日期、稅額,按月份分頁,最後加上 SUMIFS 公式與總額。

    📌
    官方特別強調:產出的試算表包含 working VLOOKUP、conditional formatting、multiple tabs,而不是需要人工修復的半成品。
    04
    🎞️

    簡報從筆記到成品

    把散落的會議筆記、語音備忘錄、手寫大綱丟進資料夾,Cowork 能分析內容、規劃架構、輸出 PowerPoint 簡報。你可以指定頁數、風格、每頁要強調的重點,它會照著做;搭配 _context/ 內預先寫好的樣式偏好,字型與配色還能維持品牌一致。

    💡
    進階玩法:讓 Cowork 準備結構化大綱,再丟進 Gamma 生成視覺效果更豐富的簡報,兩個工具各司其職。
    05
    🔌

    連接外部工具自動化工作流

    透過 Connectors,Cowork 可以連接 Google Drive、Gmail、Slack、Notion、Asana、DocuSign 等外部服務,把原本需要在多個平台之間人工切換的工作,壓縮成一個自然語言指令。例如:

    從 Google Drive 讀取講師進度表→分析各講師卡在哪個階段→輸出含顏色標記的 Excel 追蹤報告→列出每位講師的優先跟進事項
    定位:跨工具整合是 Cowork 最強大的場景之一
    06
    ⏰

    排程例行任務全自動化

    每週固定重複的工作,可以用 /schedule 設定自動排程,你回來就有成品。例如:

    每週一 09:00 觸發→掃描上週新增的檔案→生成週報→輸出到指定資料夾
    適合誰:需要定期彙整進度、追蹤數據、產出固定格式報告的工作角色
    ⚠️
    前提條件:電腦保持開機、Claude Desktop 保持開啟,任務才會在排定時間自動執行。
    🌐
    延伸場景:搭配 Chrome 擴充與 Computer use,Cowork 還能直接操作瀏覽器與桌面軟體 — 填表單、擷取網站資料、處理沒有 API 的傳統系統。詳見完整功能導覽。

    安全與信任

    給 AI 存取電腦檔案,真的安全嗎?

    Anthropic 內建了多層保護,但仍有兩個你必須認識的風險。了解界線,你才能放心委派任務。

    已內建的保護

    • 沙箱化存取:Claude 只能存取你指定的資料夾,無法讀取電腦其他位置。
    • 刪除前先問:任何破壞性操作(刪檔、覆蓋)都會先要你確認。
    • 計畫預覽:執行複雜任務前先列出每一步,等你核准。
    • 本地儲存:對話與檔案紀錄存在本機,不會上傳第三方伺服器。

    你仍要警覺的風險

    • Prompt Injection:處理外部資料(網頁、PDF)時,惡意指令可能藏在內容中,誘導 Claude 做出意外動作。
    • 指令模糊:模糊或多解的指令可能導致意外結果。提示越具體越安全。
    • 用量配額:複雜任務消耗的訊息額度可達一般對話的數十倍,計畫好優先順序。
    • 測試時用備份:首次跑新流程,先用複製的檔案,確認結果再對正本動手。

    是不是你的菜?

    適合誰用、不適合誰用

    Cowork 不是萬靈丹。看看你是不是它的甜蜜點。

    👍 適合使用者

    • 每週需定期產出相似格式文件的工作者
    • 管理多個專案、頻繁切換脈絡的人
    • 習慣用文字整理、不擅長排版的人
    • 需追蹤特定議題或客戶的業務研究人員
    • 願意花一次時間建立 SOP,長期享受成果的人

    🤔 可能不適合

    • 需要多台裝置間頻繁切換的使用者
    • 對輸出品質要求極高、零容忍錯誤的場合
    • 處理單次性、無重複性的雜事
    • 不願意建立 _context 與 CLAUDE.md 規則的人
